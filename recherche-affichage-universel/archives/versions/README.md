Les empreintes de blob permettent de vérifier que les **octets Git** des fichiers historiques restent identiques après leur déplacement. Les liens depuis le dossier racine ont été ajustés.

La [version prédécesseur](../../VERSION-1-PREDECESSEUR.md), également désignée « v1 » par convention d'archivage, reste accessible à la racine comme plus ancienne version complète disponible.

Les rapports de conservation, de propositions, les décisions et les échanges restent dans le dossier racine pour assurer la traçabilité.

**Aucune archive supprimée et aucune réécriture de l'historique Git.** Le dépôt public et la PR restent soumis aux contrôles habituels de confidentialité et de revue.
